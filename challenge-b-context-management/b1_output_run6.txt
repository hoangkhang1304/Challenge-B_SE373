| Test | Lỗi |
|------|-----|
| `auth.test.ts > refresh > concurrent refresh issues exactly one new token` | `expected 1 active refresh token for user u_42, got 2` |
| `auth.test.ts > refresh > old token rejected after rotation` | `expected 401 for reused refresh token, got 200` |
| `session.test.ts > rotation > concurrent rotation keeps single session row` | `expected 1 row in refresh_tokens(user_id=u_42, revoked=false), got 2` |

**Nguyên nhân**: Hàm `refreshToken` thực hiện 3 bước riêng biệt (SELECT → INSERT → UPDATE) **không atomic**. Khi 2 request song song dùng cùng token cũ:
1. Cả 2 đều pass SELECT (token chưa revoked)
2. Cả 2 đều INSERT token mới → tạo ra 2 token mới hợp lệ
3. Cả 2 đều UPDATE revoked=true cho token cũ

**Cần sửa**: Dùng transaction + `SELECT ... FOR UPDATE` (hoặc `UPDATE ... RETURNING`) để khóa hàng token cũ, đảm bảo chỉ 1 request thành công.

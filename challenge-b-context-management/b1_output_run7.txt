| Test | Lỗi |

| `auth.test.ts > refresh > concurrent refresh issues exactly one new token` | `expected 1 active refresh token for user u_42, got 2` |
| `auth.test.ts > refresh > old token rejected after rotation` | `expected 401 for reused refresh token, got 200` |
| `session.test.ts > rotation > concurrent rotation keeps single session row` | `expected 1 row in refresh_tokens(user_id=u_42, revoked=false), got 2` |

**Nguyên nhân**: Hàm `refreshToken` trong `session.ts` không atomic:
```typescript
const row = await db.one("SELECT ... WHERE user_id=$1 AND token=$2 AND revoked=false", ...);
if (!row) throw new Error("invalid refresh token");
const next = crypto.randomUUID();
await db.none("INSERT INTO refresh_tokens ...", ...);
await db.none("UPDATE refresh_tokens SET revoked=true WHERE token=$1", [oldToken]);
```

Khi 2 request song song cùng token:
1. Cả 2 đều pass `SELECT` (token chưa bị revoke)
2. Cả 2 `INSERT` token mới → có 2 token active
3. Cả 2 `UPDATE` revoke token cũ
4. Token cũ vẫn có thể dùng lại (vì SELECT check `revoked=false` nhưng đã bị race)

**Cần sửa**: Dùng transaction + `SELECT ... FOR UPDATE` hoặc gộp thành 1 `UPDATE ... RETURNING` atomic.
